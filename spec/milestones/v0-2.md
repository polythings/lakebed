# 0.2: Any table format, any file format

**Planned**

Applications work with a table without assuming its format: a common view of tables over the format crates, and data
files read and written through a `FileFormat` trait, Parquet first. Timelake's engine moves onto both and stops using
iceberg-rust, and lakeglass's explorer and engine use the same view.

`lakekit-parquet` with iceberg-rust only in its interop tests ([#13](https://github.com/polythings/lakekit/issues/13),
[#14](https://github.com/polythings/lakekit/issues/14)). Vortex ([#15](https://github.com/polythings/lakekit/issues/15))
follows once Iceberg lists the format.
